# 第一阶段（Milestone 1）

磨制玄武岩是为 SCP-CN 维基所制作的 CSS 主题，是玄武岩版式的**拓展差分版本**，在玄武岩本体版式的基础上进行了相当多数的样式修改、设计变动和缺陷修复，并引入（且计划还将引入）一系列自定义 div 元素，包括*div装饰类*（当前尚未实现）。本版式进行独立衍生开发的目的为降低在维基网站创作过程中对庞杂散乱的重复 CSS 代码的依赖程度与管理难度，尽可能实现“开箱即用”“即用即排版”“压缩开发量”等目的。

本版式对玄武岩的基础设计语言作出了一定的改动，以更为贴合个人审美及偏好。同时，为便于管理和泛化，本Github仓库将负责磨制玄武岩的代码托管与统一更新。

## 版式开发进度大纲

* **第一阶段（Milestone 1） - 基本适配：** 敲定本版式的基础设计语言，并实现最为基本的可用性及相关支持。
  **磨制玄武岩当前处在本阶段。**

* **第二阶段（Milestone 2） - 自定性扩展：** 提供各种由浅至深的版式自定义设置，包括但不限于版头隐藏、阴阳染色、阅读/沉浸模式、彩虹色板配色方案等。
  在该阶段结束时，该版式本体的完整代码将被同步至 SCP-CN 维基沙盒站，并进入半公开 / 公众测试状态。

* **第三阶段（Milestone 3） - 组件适配：** 为当下较为常用或个人认为具备泛用性的各组件进行针对性适配与风格统一对齐，包括但不限于各种信息模块、SCiPlook邮件模块、便利贴模块等。该阶段还将引入并内嵌多个组件，同时额外引入或开发多个新div块，如word单页块等。

* **第四阶段（Milestone 4） - 模块化装饰类与半特化预设：** 本版式的**核心理念与存在目的**之所在。
  不包含半特化预设的公众预览（Public Preview）将在模块化装饰类成型时发布，此即**磨制玄武岩发行版**的起点。

* ***（第五阶段（Milestone 5） - 半特化预设第二阶段）*** ：当然，因为模块化装饰类有可能抢在半特化预设之前就成为完成体，这个阶段被预留给剩下来不及做的半特化预设。
  > 注：根据届时的具体情况可能还有用来收尾的第六阶段（Milestone 6）。

* **候选正式版（Release Candidate）：** 残余缺陷修复与跨平台 / 向后兼容支持优化。
  进入该阶段时，本版式将正式进入完全公开状态。

* **正式版：** 版式本体转入长期维护服务阶段（LTS），直至确定开发下一版本的磨制玄武岩。
